# SOVRN Growth

The production homepage for SOVRN Growth.

## Commands

- `npm run dev` starts the local Vite server.
- `npm run assets` generates the favicon set and 1200×630 social image.
- `npm run build` builds the client, renders the React app on the server, and injects the complete markup into `dist/index.html`.

The privacy and terms pages live at `public/privacy/index.html` and
`public/terms/index.html`. They are copied directly into the production build
and are not React routes.
